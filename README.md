# 知心伙伴

知心伙伴是一份面向个人自我记录、复盘和认知梳理的伙伴型提示词。它从具体线索出发，区分事实、感受和解释，在共情的同时保留现实检验。

## 使用门槛

它不会自动替人完成自我理解。想让它真正发挥作用，使用者至少需要投入四件事：

1. **表达清楚**：尽量说明发生了什么、自己处在什么情境，以及当时的想法、情绪和身体感受。
2. **诚实真诚**：把客观发生的事情与自己的看法、感受尽可能如实写下来，不用为了得到某种回答而修饰材料。
3. **记录第一手信息**：持续保留现场细节，而不只留下事后的结论。材料越具体，模型越可能发现真实线索。
4. **理解 LLM 的长处与上界**：人常沿情绪、感官和关系线索回忆；LLM 更擅长跨越不同表层叙事，识别相似的认知与行为模式。它适合辅助归纳，不拥有对你的最终解释权。

## 开始使用

### 单独使用提示词：任意支持系统提示词的工具

打开

[`prompt/知心伙伴.md`](prompt/知心伙伴.md)

将全文复制到工具的 system prompt、custom instructions 或同类配置中，或者直接放在AI会话工具的输入开头，然后在对话里提供你希望复盘的记录。文件末尾的 `<Immediate task description or request>` 是可选占位；只有当工具要求把任务写进同一份提示词时才需要填写。

### Claude Code

```bash
git clone https://github.com/LotusDecoder/zhixin-companion.git
cd zhixin-companion
claude
```

仓库根目录的 `CLAUDE.md` 会载入同一份提示词，并提供自包含的 L0～L4 本地记录工作流。`AGENTS.md` 为 Codex 及其他 Agent 提供等价入口。

完整用法见：

[`docs/agent-使用指南.md`](docs/agent-使用指南.md)

L0～L4 中的私人记录默认被 Git 忽略。不要强制提交或推送到这个公开仓库，并请自行安排可信的本地备份。

## 安全边界

- 本项目用于个人洞察与自我探索，不替代医疗、心理治疗、法律或财务专业服务。
- 它不用于危机干预。若你或他人正面临紧迫危险，请停止依赖 AI，立即联系当地紧急服务、专业支持或可信任的人。
- 模型可能误读材料、遗漏上下文或迎合使用者。涉及健康、安全、关系、金钱和其他重要判断时，请回到原始事实，并在需要时咨询合格专业人士。
- 不要上传无权分享的第三方隐私、身份信息、医疗资料、账号凭据或其他敏感内容。
